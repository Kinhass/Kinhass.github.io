Setup status. The YouTube OAuth integration is not yet implemented or authorized. This policy sets the intended processing boundaries and requirements for activation; it is not a claim that the connection, security controls, deletion mechanisms, or Google verification have already been completed.

1. About the application

Girl Psychology Simple Automation is an owner-operated Windows desktop automation project maintained by Lucas for the Girl Psychology Simple YouTube channel. It is not a public service for connecting third-party channels and provides no public account registration.

The application is intended to use YouTube API Services after the channel owner grants authorization. The owner must review and agree to this privacy policy and the YouTube Terms of Service before activating the integration. Google and YouTube handle their own services under the Google Privacy Policy.

2. Data accessed and its purpose

Once implemented and authorized, supported functions are intended to upload owner-selected videos, manage publishing information, captions and playlists, set publication schedules, and create owner-prepared comments. Features not supported by the public API may use YouTube Studio separately.

Data processing may include:

  • Channel and video identifiers, titles, descriptions, tags, thumbnails, captions and playlist information.
  • Video files selected by the owner, visibility settings, scheduled and actual publication times, and upload or processing results.
  • The text and identifiers of comments prepared by the owner, plus status information needed to verify those actions.
  • OAuth authorization credentials and limited operational records necessary to carry out the requested workflow.

Only permissions needed for implemented, owner-authorized functions may be requested. The proposed youtube.force-ssl permission is broad, but its technical capabilities are not permission to delete existing channel content or perform unrelated actions. New data uses require an updated disclosure and renewed consent where required.

3. Desktop storage and security

This static website is not an OAuth login service. It does not receive Google passwords, authorization codes, access tokens or refresh tokens. OAuth configuration and credentials must remain outside the public website and its repository.

The intended desktop design uses operator-controlled local storage for credentials and workflow records. Before activation, the operator must document and verify the actual storage locations, appropriate access protections, token refresh and revocation behavior, and deletion procedures. Local storage alone is not a claim of encryption or sufficient security.

Secrets must not be included in public commits, screenshots, general chat messages, media folders or control spreadsheets. The integration must not be activated until required protections and data-handling procedures are in place.

4. External services and necessary processing

Authorized API operations communicate with Google and YouTube. Owner-directed automation may also involve a configured AI provider or a separately authorized Google Sheets workflow when necessary for the requested functionality. The website itself performs none of those API operations.

Before transferring Google API user data to another processor, the operator must identify that provider, the data categories, the purpose, and applicable storage and deletion conditions, and obtain any required consent. A generic reference to AI tools is not permission for undisclosed transfers.

Only the minimum necessary data may be transferred. If a provider's terms or settings cannot support these commitments, Google API user data must not be sent to that provider. Google API data must not be sold, used for advertising targeting, or used or transferred for training generalized artificial-intelligence or machine-learning models.

5. Google API Services and Limited Use

Girl Psychology Simple Automation's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including applicable Limited Use requirements. Google user data is restricted to the disclosed, owner-facing functionality. Transfers and human access are limited to circumstances permitted by that policy.

This is a processing commitment and an activation requirement, not evidence that Google has audited or approved the unfinished integration.

6. Retention, refresh and deletion

The integration's retention and deletion mechanisms are not yet implemented. Before activation, the operator must establish a documented procedure covering credentials, local API-derived records, and any permitted external copies, including data copied into logs or spreadsheets.

Stored YouTube API data must be refreshed or deleted according to the applicable YouTube API Services Developer Policies. For most other authorized and non-authorized API data, the maximum period before refresh or deletion is 30 calendar days; tokens and specifically permitted data categories have different rules. This is not a promise to delete all project files or all credentials every 30 days.

When applicable, deletion requests and revocation through the application require deletion as soon as possible and within seven calendar days. Application-mediated revocation also requires immediate programmatic token revocation. Revocation through Google's security settings requires deletion of associated API data as soon as possible and within 30 calendar days, with the required authorization checks.

Removing the application's data copies or credentials does not itself delete videos, captions, playlists or comments already published on YouTube. Those remain subject to the owner's YouTube controls and YouTube's own terms.

7. Your control and revoking access

The channel owner chooses whether to authorize the integration and which supported actions it may perform. A grant can be reviewed or revoked in Google's account permissions settings.

Before activation, the desktop client must also provide a clearly documented way to disconnect, revoke its token and initiate deletion of associated API data. The required local procedure is not yet implemented, so this website does not claim to offer a working disconnect button.

Privacy questions, complaints and deletion requests can be sent to lucas.antoni.conceicao@gmail.com. Do not include passwords, authorization codes or tokens in a request.

8. Website, device storage and hosting

These informational pages contain no public sign-in, submission forms, application analytics scripts or advertising trackers. They do not set application cookies or browser local-storage records. The desktop application's eventual local credentials and records are separate from this website.

The public pages are hosted on GitHub Pages. GitHub may process request information such as an IP address and technical logs under its own privacy statement. Links to Google, YouTube and other external services lead to their own sites and policies.
